# صفحه اصلی گیلاکلیک (GilaClick)

صفحه اصلی اختصاصی [gilaclick.ir](https://gilaclick.ir) با هویت بصری «سبز دیجیتال»، مدارهای الکترونیکی زنده، سیستم حرکتی کامل و داده‌ی **زنده** محصولات از فروشگاه ووکامرس.

- **فناوری:** فقط **HTML + CSS + JavaScript خالص** — بدون فریم‌ورک، بدون کتابخانه، بدون مرحله Build. فایل‌ها همان‌طور که هستند روی هاست قرار می‌گیرند.
- **زبان و جهت:** تمام محتوا فارسی و راست‌چین؛ فونت Vazirmatn با میزبانی محلی (بدون Google Fonts یا CDN).
- **حجم انتقالی (gzip):** HTML حدود ۲۱KB · CSS حدود ۳۰KB · JS حدود ۲۳KB · زیرمجموعه فارسی فونت ۴۶KB.
- **Lighthouse نسخه اصلی:** در یک آزمون محلی، Performance موبایل ۹۳ و دسکتاپ ۹۸، Accessibility و SEO برابر ۱۰۰ و CLS نزدیک صفر بود. تصاویر سایت در آن محیط قابل دریافت نبودند؛ این اعداد به دو خروجی جدید، فونت واقعی پیدا یا سایت المنتوری تعمیم داده نمی‌شوند.

## خروجی‌های تک‌فایل و المنتور

دو فایل کنار نسخه اصلی قرار دارند:

| فایل | کاربرد |
| --- | --- |
| `gilaclick-single.html` | همان صفحه به‌صورت HTML با CSS و JavaScript داخل خود فایل؛ فایل‌های فونت، تصاویر و داده فروشگاه جدا هستند. |
| `gilaclick-elementor.json` | قالب صفحه برای واردکردن در Elementor 4 با Container و ویجت‌های کلاسیک المنتور. |

### نصب HTML مستقل و فونت پیدا

1. فایل HTML را روی همان دامنه سایت از طریق وب‌سرور قرار دهید، نه با آدرس `file://`. برای فونت جایگزین، پوشه `assets/fonts/` را در مسیر نسبی کنار فایل نگه دارید. اگر صفحه را به‌عنوان صفحه اصلی با rewrite سرو می‌کنید، درخواست مرورگر به `/assets/fonts/` را نیز به همان پوشه هدایت کنید.
2. نام `Peyda` در CSS اولویت اول است؛ اما نصب فونت در وردپرس به‌خودی‌خود آن را به یک فایل HTML استاتیک اضافه نمی‌کند. آدرس واقعی فایل‌های دارای مجوز پیدا را از تنظیمات فونت سایت یا هاست بردارید و نمونه `@font-face` کامنت‌شده در ابتدای HTML را با URL و وزن‌های درست کامل و فعال کنید. فایل پیدا داخل این خروجی قرار داده نشده است. تا زمان بارگذاری آن، Vazirmatn و سپس فونت‌های سیستمی جایگزین می‌شوند.
3. تصاویر راهنمای گیلان از کتابخانه رسانه سایت بارگذاری می‌شوند. محصولات و سبد خرید از مسیر `/wp-json/wc/store/v1` همان دامنه خوانده می‌شوند؛ در پیش‌نمایش محلی یا دامنه دیگر باید API و دسترسی CORS را جداگانه تنظیم و بررسی کنید. بقیه آدرس‌های سایت، مانند فروشگاه، باید همچنان در اختیار وردپرس بمانند؛ فایل اصلی وردپرس را جایگزین نکنید.
4. پس از اتصال فونت واقعی، مخصوصاً شکست خطوط تیترها و چیدمان موبایل و دسکتاپ را بررسی کنید؛ تفاوت اندازه حروف فونت‌ها می‌تواند ظاهر را تغییر دهد.

### واردکردن و ویرایش قالب المنتور

1. ابتدا از سایت و پایگاه داده نسخه پشتیبان بگیرید و قالب را در یک صفحه آزمایشی بررسی کنید. در پیشخوان به **Templates / قالب‌ها ← Saved Templates / قالب‌های ذخیره‌شده ← Import Templates / واردکردن قالب** بروید و `gilaclick-elementor.json` را وارد کنید. نام منو ممکن است با زبان و نسخه المنتور کمی تفاوت داشته باشد.
2. یک صفحه تازه با المنتور باز کنید، طرح‌بندی صفحه را **Elementor Canvas** بگذارید و قالب واردشده را از کتابخانه قالب‌های ذخیره‌شده در صفحه درج کنید. Container و nested elements باید فعال باشند. سپس صفحه را ذخیره و نسخه منتشرشده را بررسی کنید.
3. در **Navigator / Structure** مسیر «بخش‌های صفحه ← نام بخش ← ویرایش محتوا: نام بخش» را باز کنید. در آنجا متن‌ها، عنوان‌ها، دکمه‌ها و آدرس‌ها با ویجت‌های Heading، Text Editor و Button و تصاویر راهنمای گیلان با Image ویرایش می‌شوند. عنوان اصلی دو کنترل جدا برای قسمت سفید و سبز دارد؛ توضیح زیر تصاویر و آدرس هر کارت راهنمای گیلان نیز کنترل جدا دارد. محتوای محصولات واقعی، از جمله نام، قیمت و عکس محصول، در خود ووکامرس تغییر می‌کند.
4. ساختار این قالب **ترکیبی** است: نمای اصلی هر بخش و افکت‌های آن در ویجت HTML است و کنترل‌های محتوای المنتور در گروه جداگانه قرار دارند. بنابراین روی متن داخل نمای گرافیکی کلیک نکنید؛ کنترل متن مربوط را در گروه «ویرایش محتوا» یا Navigator انتخاب کنید. تغییرات محتوایی در پیش‌نمایش و صفحه منتشرشده منعکس می‌شوند، اما انیمیشن‌ها در محیط ویرایش برای سبک‌ترشدن خاموش‌اند. پس از هر تغییر، پیش‌نمایش منتشرشده را نیز کنترل کنید.
5. بلوک‌های «⚙️ … حذف نشود»، «نمای اصلی …» و کلاس‌ها و شناسه‌های `gc-` اتصال طرح به کنترل‌ها را نگه می‌دارند؛ آن‌ها را حذف یا تغییر ندهید و کنترل‌ها را از گروه بخش خود بیرون نبرید. **تب‌های Style و Advanced ویجت‌های کنترل محتوا، و افزودن ویجت جدید به آن گروه، به‌طور خودکار استایل یا چیدمان بخش نهایی را تغییر نمی‌دهند.** تغییر چیدمان، رنگ و افکت نیاز به ویرایش CSS/HTML طرح دارد. سربرگ و منوی موبایل HTML هستند؛ تغییر لینک‌های آن‌ها باید در هر دو ویجت انجام شود.
6. اگر هنگام import نتواند تصویر خارجی را به کتابخانه منتقل کند، کنترل تصویر ممکن است placeholder نشان دهد؛ تصویر اصلی تا انتخاب تصویر جدید در صفحه باقی می‌ماند. برای جایگزینی، تصویر را از کتابخانه رسانه انتخاب و متن جایگزین آن را تنظیم کنید.
7. نام فونت سفارشی سایت باید دقیقاً `Peyda` باشد و فایل‌ها و وزن‌های آن در فرانت‌اند بارگذاری شوند؛ در غیر این صورت نام را در CSS قالب اصلاح یا بارگذاری فونت را تنظیم کنید. فایل JSON شامل فونت جایگزین Vazirmatn است، نه فایل تجاری پیدا. تنظیمات قالب، المنتور، افزونه‌ها، مسدودکننده اسکریپت و کش می‌توانند بر نتیجه اثر بگذارند. در صورت نیاز به حذف درخواست‌های Google Fonts، تنظیم بارگذاری آن را در تنظیمات المنتور غیرفعال و CSS و کش سایت را بازسازی کنید.
8. اجرای JavaScript برای اعمال تغییرات کنترل‌های المنتور در صفحه نهایی و برای محصولات زنده لازم است؛ بهینه‌سازها نباید اسکریپت‌ها یا استایل‌های داخلی این قالب را حذف یا تا تعامل کاربر به تعویق بیندازند. عنوان سئو، توضیحات، canonical، Open Graph و داده ساختاریافته نسخه المنتور را در وردپرس یا افزونه SEO سایت تنظیم کنید.

**محدوده آزمون:** import، انتخاب و ذخیره عملی عنوان، متن، دکمه و لینک و انتخاب تصویر از کتابخانه رسانه در یک محیط آزمایشی WordPress و Elementor 4.0.0 بدون Pro بررسی شد. ریسپانسیو، منوی موبایل، انیمیشن‌ها و حالت‌های API با داده آزمایشی بررسی شدند؛ فونت پیدا، تصاویر اصلی، Elementor Pro و افزونه‌های سایت شما در آن محیط در دسترس نبودند. پیش از انتشار، این موارد و Lighthouse را روی نسخه واقعی سایت بسنجید؛ امتیاز ۱۰۰ تضمین‌شدنی نیست.

## پیش‌نمایش محلی

مخزن فقط خود سایت است و به نصب هیچ بسته‌ای نیاز ندارد. پوشه را با هر وب‌سرور استاتیک باز کنید، مثلاً:

```bash
python3 -m http.server 8000   # →  http://localhost:8000
```

- هر سرور استاتیک دیگری (مثل `npx serve` یا افزونه Live Server در VS Code) هم کافی است. باز کردن مستقیم `index.html` از دیسک (`file://`) هم کار می‌کند، اما مرورگر در این حالت فونت را مسدود می‌کند.
- در پیش‌نمایش محلی، بخش محصولات پیام «نمایش زنده محصولات در این لحظه ممکن نشد» را همراه با لینک فروشگاه نشان می‌دهد؛ چون ووکامرس فقط به دامنه خود سایت اجازه CORS می‌دهد. روی gilaclick.ir محصولات به‌صورت زنده از فروشگاه خوانده می‌شوند.
- ابزارهای توسعه قبلی (سرور پیش‌نمایش با داده نمونه فروشگاه، تولید اسپرایت آیکن و اعتبارسنجی HTML) برای سبک ماندن مخزن حذف شده‌اند و در صورت نیاز در تاریخچه گیت (کامیت `ef6cd65`) موجودند.

## ساختار پروژه

```
index.html                 ← نسخه اصلی: محتوا، ساختار، سئو، قالب‌های کارت محصول و تنظیمات اجرا
gilaclick-single.html      ← نسخه تک‌فایلی HTML با CSS و JavaScript داخلی
gilaclick-elementor.json   ← قالب صفحه برای import در Elementor 4
assets/
├── css/
│   ├── tokens.css         ← رنگ‌ها، تایپوگرافی، فاصله‌ها، زمان‌بندی حرکت
│   ├── base.css           ← فونت، ریست، ابزارهای پایه
│   ├── components.css     ← دکمه‌ها، تیتر سکشن‌ها، افکت‌های مشترک کارت‌ها
│   ├── layout.css         ← هدر، زیرمنوها، منوی موبایل، نوار پیشرفت، ریل سکشن‌ها، فوتر
│   ├── circuits.css       ← ظاهر و انیمیشن مدارها
│   ├── sections.css       ← سکشن‌ها به ترتیب صفحه
│   └── motion.css         ← سیستم ظاهر شدن، keyframeها، حالت کاهش حرکت
├── js/
│   ├── core.js            ← ابزارها، حلقه مشترک اسکرول، ثبت ماژول‌ها
│   ├── circuits.js        ← تولید همه تصاویر مداری (SVG) در مرورگر
│   ├── motion.js          ← ظاهر شدن، تیترهای کلمه‌به‌کلمه، شمارنده، افکت‌های نشانگر، ریل، …
│   ├── header.js          ← هدر، خط متحرک منو، زیرمنوها، منوی موبایل، شمارنده سبد
│   ├── products.js        ← خواندن محصولات از Store API و پر کردن قالب‌ها
│   └── main.js            ← شروع ماژول‌ها
├── fonts/                 ← Vazirmatn (فارسی و لاتین) + مجوز OFL
└── img/                   ← فاوآیکن و تصویر اشتراک‌گذاری (og-image)
```

برای استقرار **نسخه اصلی**، `index.html` و پوشه `assets/` لازم است. راه نصب دو خروجی دیگر در بخش «خروجی‌های تک‌فایل و المنتور» آمده است.

### ویرایش

- **متن‌ها و لینک‌ها:** مستقیماً در `index.html`؛ هر سکشن با توضیح (`<!-- 1. HERO -->` و …) مشخص شده است.
- **تنظیمات اجرا:** بلوک `<script type="application/json" id="gc-config">` در انتهای `index.html` — آدرس Store API، آدرس سبد خرید، تعداد محصولات، شناسه محصول شاخص و خلاصه کارت‌ها.
- **رنگ‌ها، فاصله‌ها و سرعت حرکت‌ها:** `assets/css/tokens.css`.
- **آیکن جدید:** کد SVG آیکن را از [Lucide](https://lucide.dev/icons) بردارید و عناصر داخل آن (`<path>`، `<circle>` و …) را در یک `<symbol id="i-NAME" viewBox="0 0 24 24">` تازه داخل اسپرایت ابتدای `<body>` در `index.html` (بین `icons:start` و `icons:end`) بگذارید؛ رنگ و ضخامت خط از کلاس `.icon` می‌آید. سپس:
  `<svg class="icon" width="20" height="20" aria-hidden="true" focusable="false"><use href="#i-NAME" /></svg>`

## داده واقعی؛ بدون محتوای ساختگی

### محصولات
بخش محصولات در مرورگر از **WooCommerce Store API** همان سایت خوانده می‌شود (`assets/js/products.js`). هیچ نام، قیمت، تصویر یا لینک محصولی در کد نوشته نشده است.

| داده | منبع |
| --- | --- |
| نام، قیمت، تصویر، دسته‌بندی، لینک | مستقیماً از Store API |
| ویژگی‌های کارت شاخص | تیترهای شماره‌دار («۱. …») توضیحات همان محصول در ووکامرس |
| خلاصه کارت | «توضیح کوتاه» محصول در ووکامرس؛ تا وقتی خالی است، متن بریف از `gc-config` |
| قیمت | قالب‌بندی فارسی (`۱٬۴۸۰٬۰۰۰ تومان`)، پشتیبانی از تخفیف و بازه قیمت؛ اگر قیمت در API نباشد «قیمت در صفحه محصول» |

- **محصول شاخص:** محصول «ویژه» (ستاره‌دار) در ووکامرس؛ در غیر این صورت `preferredFeaturedId` (فعلاً «پلاگین تماس برای قیمت» طبق بریف) و در نهایت جدیدترین محصول.
- **چیدمان خودکار:** کارت شاخص + ستون کناری؛ با اضافه شدن محصول، ردیف‌های سه‌تایی خودکار ساخته می‌شوند.
- **حالت‌ها:** اسکلت بارگذاری هم‌اندازه کارت‌های نهایی (بدون پرش چیدمان)؛ اگر API در دسترس نباشد یا محصولی نباشد، پیام شفاف و لینک فروشگاه. بدون جاوااسکریپت هم لینک فروشگاه نمایش داده می‌شود.
- کارت «ابزارهای مدیریتی و نرم‌افزارهای اختصاصی» محصول فروشگاه نیست؛ بدون قیمت و با دکمه درخواست مشاوره.
- **سبد خرید:** «افزودن به سبد خرید» با سازوکار استاندارد ووکامرس (`/cart/?add-to-cart=ID`). شمارنده سبد هدر فقط وقتی فعال می‌شود که کوکی ووکامرس نشان دهد سبد خالی نیست.

### تصاویر راهنمای گیلان
عکس‌های واقعی از کتابخانه رسانه gilaclick.ir: پارک جنگلی سراوان، کافه آدرس رشت، خانه موزه میرزا کوچک خان (معماری بومی گیلانی) و بازار بزرگ رشت.

### آمار
هیچ آمار یا درصد ساختگی وجود ندارد؛ تنها عدد صفحه «بیش از ۱۰ سال تجربه» است که در بریف آمده.

## سیستم حرکت

همه حرکت‌ها با CSS و جاوااسکریپت سبک ساخته شده‌اند (بدون کتابخانه و بدون ویدئو) و فقط روی `transform`، `opacity`، `clip-path` و `stroke-dashoffset` کار می‌کنند؛ بنابراین هیچ حرکتی باعث جابه‌جایی چیدمان نمی‌شود.

| بخش | حرکت‌ها |
| --- | --- |
| سراسری | نوار پیشرفت اسکرول، ریل مداری سکشن‌ها با نقطه فعال (دسکتاپ)، دکمه بازگشت به بالا با حلقه پیشرفت، نور همراه نشانگر روی سطوح تیره، ظاهر شدن پلکانی، تیترهای کلمه‌به‌کلمه، رسم خط مدار بالای هر تیتر، خط‌کش سبز زیر عبارت‌های کلیدی، دکمه‌های مغناطیسی با موج کلیک و درخشش، کارت‌های سه‌بعدی با نور و بازتاب |
| هدر | ورود نرم، خط متحرک زیر منو، باز شدن پلکانی زیرمنو، رسم لوگو، منوی موبایل پلکانی |
| هیرو | تیتر کلمه‌به‌کلمه با گرادیان متحرک، رسم مدارها با پالس‌های نوری و فلش رسیدن، شفق متحرک، ذرات داده، پارالاکس نشانگر و اسکرول، تایپ کد خط‌به‌خط، چرخه «ساخت ← آزمون ← انتشار»، گفتگوی چرخشی دستیار Hami، کلید روشن‌شونده افزونه، شمارنده ۰←۱۰ |
| محصولات | پرتو نوری دور کارت شاخص، خط اسکن روی تصویر، حاشیه روشن دنبال‌کننده نشانگر، ظاهر شدن ویژگی‌ها |
| خدمات | پرتو چرخان دور کارت، روشن شدن پلکانی موارد، سلول‌های چشمک‌زن شبکه |
| توانمندی‌ها | تراشه مرکزی با حلقه‌های چرخان و پین‌های زنده، رسم مدار با اسکرول، روشن شدن کلمه‌به‌کلمه پاراگراف‌ها، نوار متحرک فناوری‌ها و خدمات، رمزگشایی برچسب‌ها |
| برنامه آینده | خط اسکنر نقشه، مسیر خط‌چین متحرک، سیگنال روان روی مسیر، نشان «در حال توسعه» چرخان |
| راهنمای گیلان | ورود کاشی‌ها با پرده، پارالاکس داخل قاب، کج شدن سه‌بعدی، پینگ نشانگر مکان |

| مسیر همکاری | ریل رسم‌شونده با اسکرول، بسته نوری سر ریل، روشن شدن هر مرحله با رسیدن ریل |
| فراخوان پایانی | حاشیه نوری چرخان، شفق چرخان، نورافکن نشانگر، ذرات، مدارهای رسم‌شونده |

**رابط داده‌ای حرکت** (برای افزودن به المان‌های جدید):

| ویژگی | کار |
| --- | --- |
| `data-reveal` (`up` · `fade` · `scale` · `start` · `end` · `clip`) | ظاهر شدن یک‌باره هنگام ورود به دید |
| `data-stagger` | شماره‌گذاری خودکار تأخیر فرزندان |
| `data-split` | ظاهر شدن کلمه‌به‌کلمه تیتر |
| `data-tilt="4"` · `data-spotlight` · `data-magnetic` | کج شدن سه‌بعدی · نور دنبال‌کننده · کشش مغناطیسی |
| `data-progress` | متغیر `--p` (پیشرفت اسکرول ۰ تا ۱) برای پارالاکس و رسم مدار |
| `data-visibility` | توقف انیمیشن‌های پیوسته خارج از دید |
| `data-count-to` · `data-scramble` · `data-scroll-words` | شمارنده · رمزگشایی متن لاتین · روشن شدن کلمه‌ها |
| `data-circuit` + `data-draw` (`load` · `scroll` · `reveal`) | زمینه مداری و نحوه رسم آن |

**عملکرد و احترام به کاربر**
- `prefers-reduced-motion`: همه حرکت‌ها حذف و همه چیز در حالت نهایی و ثابت نمایش داده می‌شود.
- موبایل و صفحه لمسی: بدون کج شدن، کشش مغناطیسی، نور نشانگر، پارالاکس و ریل؛ زمینه‌های مداری و ذرات کمتر.
- انیمیشن‌های پیوسته در سکشن‌های خارج از دید متوقف می‌شوند؛ مدارهای پایین صفحه کمی قبل از رسیدن به آن‌ها ساخته می‌شوند.
- همه افکت‌های اسکرول در یک حلقه مشترک با حداکثر یک فریم در هر رفرش اجرا می‌شوند و خواندن و نوشتن چیدمان از هم جدا است (بدون layout thrashing). شنونده‌ها `passive` هستند و هیچ لایه تزئینی لمس یا کلیک را نمی‌گیرد.
- اگر جاوااسکریپت اجرا نشود یا خطا بدهد، همه محتوا حداکثر پس از ۳ ثانیه دیده می‌شود.

**دسترس‌پذیری و سئو**
- یک `h1`، یک `h2` برای هر سکشن، `h3` برای کارت‌ها؛ لندمارک‌های استاندارد و لینک «پرش به محتوا».
- زیرمنوها با ماوس، لمس و صفحه‌کلید؛ منوی موبایل با قفل فوکوس، Escape و غیرفعال کردن پس‌زمینه.
- متا تگ‌ها، Open Graph، داده ساختاریافته `Organization` و `WebSite` (با جستجوی سایت).

## استقرار

### روی همان دامنه gilaclick.ir (پیشنهادی)
در این حالت Store API هم‌مبدأ است و بدون تنظیم اضافه کار می‌کند. `index.html` و `assets/` را مثلاً در `public_html/gilaclick-home/` بارگذاری کنید.

**Apache / LiteSpeed** — این قوانین را **قبل از** قوانین وردپرس در `.htaccess` بگذارید:

```apache
RewriteEngine On
RewriteRule ^$ /gilaclick-home/index.html [L]
RewriteRule ^assets/(.*)$ /gilaclick-home/assets/$1 [L]
```

**Nginx:**

```nginx
location = / { root /var/www/gilaclick-home; try_files /index.html =404; }
location ^~ /assets/ { root /var/www/gilaclick-home; expires 7d; }
```

فقط آدرس ریشه (`/`) و `/assets/` به صفحه جدید می‌رسند؛ فروشگاه، حساب کاربری، API و بقیه مسیرها مثل قبل در اختیار وردپرس است.

- **فشرده‌سازی** gzip یا Brotli را برای HTML، CSS، JS و SVG فعال نگه دارید (حجم را حدود ۵ برابر کم می‌کند).
- نام فایل‌ها نسخه‌دار نیستند؛ اگر کش طولانی تنظیم می‌کنید، پس از هر به‌روزرسانی به آدرس فایل‌ها یک نسخه اضافه کنید (مثلاً `sections.css?v=2`).
- اگر مسیر تصویر اشتراک‌گذاری تغییر کرد، آدرس `og:image` و `twitter:image` را در `index.html` به‌روز کنید.

### روی دامنه یا هاست دیگر
در `gc-config` مقدار `storeApi` را آدرس کامل قرار دهید (`https://gilaclick.ir/wp-json/wc/store/v1`) و دامنه جدید را در وردپرس مجاز کنید (مثلاً در `functions.php` قالب فرزند):

```php
add_filter( 'allowed_http_origins', function ( $origins ) {
    $origins[] = 'https://landing.example.com';
    return $origins;
} );
```

## مواردی که به تصمیم یا اطلاعات شما نیاز دارد

1. **اطلاعات تماس و شبکه‌های اجتماعی:** در سایت فعلی ایمیل، تلفن یا صفحه اجتماعی عمومی پیدا نشد و چیزی ساخته نشد. در فوتر `index.html` دو بلوک آماده (به‌صورت توضیح) وجود دارد؛ آدرس‌ها را جایگزین و از حالت توضیح خارج کنید. آیکن تلگرام، اینستاگرام، واتس‌اپ و آپارات در اسپرایت موجود است.
2. **صفحات خدمات و تعرفه:** صفحه‌ای برای «تعرفه طراحی سایت»، «خدمات سئو» و «تعرفه پشتیبانی» وجود ندارد؛ این دکمه‌ها فعلاً به صفحه تماس می‌روند.
3. **دسته اقامتگاه‌ها:** دسته‌ای برای اقامتگاه وجود ندارد؛ کارت «اقامتگاه‌ها» به جستجوی سایت برای «اقامتگاه» لینک شده است.
4. **توضیح کوتاه محصولات:** «توضیح کوتاه» محصولات در ووکامرس خالی است؛ با پر کردن آن، متن کارت‌ها مستقیماً از فروشگاه خوانده می‌شود.
5. **محصول شاخص:** با ستاره‌دار کردن یک محصول در ووکامرس، همان محصول در کارت بزرگ قرار می‌گیرد.
6. **لوگو:** نشانه SVG هماهنگ با هویت جدید طراحی شده است؛ در صورت تمایل می‌توان لوگوی رسمی را جایگزین کرد.

**مشاهدات جانبی از سایت فعلی** (خارج از این مخزن):
- قیمت‌های صفحه اصلی فعلی (۸۹۰٬۰۰۰ و ۱٬۴۵۰٬۰۰۰ تومان) با قیمت‌های واقعی فروشگاه یکسان نیست؛ صفحه جدید قیمت را فقط از فروشگاه می‌خواند.
- در صفحه محصولات عبارت‌های «ارسال به سراسر ایران / ضمانت تعویض کالا» دیده می‌شود که برای محصول دانلودی مناسب نیست.
- عنوان سایت در وردپرس «معرفی گیلان» است و در عنوان همه صفحات دیده می‌شود.
