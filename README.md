# صفحه اصلی گیلاکلیک (GilaClick)

صفحه اصلی اختصاصی [gilaclick.ir](https://gilaclick.ir) با هویت بصری «سبز دیجیتال»، مدارهای الکترونیکی ظریف، انیمیشن‌های اسکرول و داده‌ی **زنده** محصولات از فروشگاه ووکامرس.

- **فناوری:** [Astro](https://astro.build) با خروجی کاملاً استاتیک (HTML + CSS + کمی جاوااسکریپت)، بدون فریم‌ورک سنگین سمت کاربر
- **زبان و جهت:** تمام محتوا فارسی و راست‌چین، فونت Vazirmatn (میزبانی محلی، بدون وابستگی به Google Fonts یا CDN)
- **حجم انتقالی (gzip):** HTML حدود ۲۱KB، CSS حدود ۱۵KB، JS حدود ۵KB، به‌علاوه زیرمجموعه فارسی فونت (۴۶KB)

---

## اجرا

نیازمندی: Node.js نسخه ۲۲٫۲۲ یا بالاتر.

```bash
npm install
npm run dev        # سرور توسعه روی http://localhost:4321
npm run build      # خروجی نهایی در پوشه dist/
npm run preview    # اجرای خروجی dist/ به‌همراه داده نمونه فروشگاه
npm run check      # بررسی تایپ‌ها و قالب‌ها
```

> در حالت `dev` و `preview`، مسیر `/wp-json/wc/store/v1/products` با یک **نسخه ثبت‌شده از پاسخ واقعی API فروشگاه** (تاریخ ۸ آبان ۱۴۰۵) پاسخ داده می‌شود؛ چون ووکامرس فقط به دامنه خود سایت اجازه دسترسی CORS می‌دهد. این داده هرگز وارد خروجی نهایی نمی‌شود. برای آزمودن حالت‌های خطا: `STORE_FIXTURE=error npm run preview` (یا `empty` و `slow`).

## داده واقعی؛ بدون محتوای ساختگی

### محصولات
بخش محصولات در مرورگر از **WooCommerce Store API** همان سایت خوانده می‌شود (`src/scripts/products/`):

| داده | منبع |
| --- | --- |
| نام، قیمت، تصویر، دسته‌بندی، لینک | مستقیماً از Store API |
| ویژگی‌های کارت شاخص | تیترهای شماره‌دار («۱. …») همان توضیحات محصول در ووکامرس |
| خلاصه کارت | «توضیح کوتاه» محصول در ووکامرس؛ تا وقتی خالی است، متن بریف از `store.summaries` |
| قیمت | قالب‌بندی فارسی (`۱٬۴۸۰٬۰۰۰ تومان`)، پشتیبانی از تخفیف و بازه قیمت؛ اگر قیمت در API نباشد «قیمت در صفحه محصول» نمایش داده می‌شود |

- **محصول شاخص:** محصولی که در ووکامرس «ویژه» (ستاره) شده باشد؛ در غیر این صورت `preferredFeaturedId` (فعلاً «پلاگین تماس برای قیمت»، طبق بریف) و در نهایت جدیدترین محصول.
- **چیدمان خودکار:** کارت شاخص + ستون کناری؛ با اضافه شدن محصولات جدید، ردیف‌های سه‌تایی به‌طور خودکار ساخته می‌شوند.
- **حالت‌ها:** اسکلت بارگذاری هم‌اندازه کارت‌های نهایی (بدون پرش چیدمان)؛ اگر API در دسترس نباشد یا محصولی نباشد، پیام شفاف + لینک فروشگاه. **هیچ محصول یا قیمت جایگزینی ساخته نمی‌شود.**
- کارت «ابزارهای مدیریتی و نرم‌افزارهای اختصاصی» محصول فروشگاه نیست؛ بدون قیمت و با دکمه درخواست مشاوره نمایش داده می‌شود.
- **سبد خرید:** دکمه «افزودن به سبد خرید» از سازوکار استاندارد ووکامرس (`/cart/?add-to-cart=ID`) استفاده می‌کند. شمارنده سبد در هدر فقط وقتی فعال می‌شود که کوکی خود ووکامرس نشان دهد سبد خالی نیست (بدون ساختن نشست برای بازدیدکنندگان).

### تصاویر راهنمای گیلان
عکس‌های واقعی از کتابخانه رسانه خود gilaclick.ir انتخاب شده‌اند (هر کدام بررسی شد که عکس واقعی باشد؛ یک تصویر «مرکز خرید» که ساخته هوش مصنوعی بود کنار گذاشته شد):

| دسته | عکس |
| --- | --- |
| جاذبه‌های گردشگری | پارک جنگلی سراوان |
| رستوران‌ها و کافه‌ها | کافه آدرس، رشت |
| اقامتگاه‌ها | خانه موزه میرزا کوچک خان (معماری بومی خانه گیلانی) |
| فروشگاه‌ها و کسب‌وکارها | بازار بزرگ رشت |

### آمار
هیچ آمار یا درصد ساختگی در صفحه وجود ندارد؛ تنها ادعای عددی «بیش از ۱۰ سال تجربه» است که در بریف آمده.

## ساختار پروژه

```
src/
├── config/
│   ├── site.ts            ← همه لینک‌ها، تنظیمات فروشگاه، اطلاعات تماس و شبکه‌های اجتماعی
│   └── navigation.ts      ← منوی اصلی، زیرمنوها و ستون‌های فوتر
├── data/                  ← متن هر سکشن (یک فایل برای هر سکشن)
├── components/
│   ├── sections/          ← Hero، Products، Services، Capabilities، Roadmap، GilanGuide، Benefits، Process، FinalCta
│   ├── circuits/          ← تصویرسازی‌ها و زمینه‌های مداری (SVG)
│   ├── layout/            ← Header و Footer
│   ├── brand/Logo.astro
│   └── ui/                ← Button، Icon، SectionHeading
├── lib/circuit.ts         ← هندسه مسیرهای PCB (باس‌های موازی با خم ۴۵ درجه)، در زمان build
├── scripts/
│   ├── main.ts
│   ├── modules/           ← هدر، منو، ظاهر شدن با اسکرول، پیشرفت اسکرول، توقف انیمیشن خارج از دید، …
│   └── products/          ← API، مدل داده و رندر محصولات
├── styles/                ← توکن‌های طراحی، پایه، سیستم حرکت
└── assets/                ← فاوآیکن و تصویر اشتراک‌گذاری (og-image)
dev/
├── store-api-fixture.mjs  ← پاسخ نمونه Store API (فقط توسعه/پیش‌نمایش)
├── fixtures/store-api/products.json
├── preview-server.mjs
└── og/og-image.html       ← منبع تصویر اشتراک‌گذاری
```

**تغییر متن‌ها:** فایل‌های `src/data/*.ts` · **تغییر لینک‌ها:** فقط `src/config/site.ts` · **رنگ‌ها و فاصله‌ها:** `src/styles/tokens.css`

## استقرار

خروجی `npm run build` فقط شامل `index.html` و پوشه `_astro/` است.

### ۱. روی همان دامنه gilaclick.ir (پیشنهادی)
در این حالت Store API هم‌مبدأ است و بدون هیچ تنظیم اضافه کار می‌کند.

**هاست cPanel / DirectAdmin (Apache یا LiteSpeed):**

```bash
ASSETS_PREFIX=/gilaclick-home npm run build
```

محتوای `dist/` را در `public_html/gilaclick-home/` بارگذاری کنید و این قانون را **قبل از** قوانین وردپرس در `.htaccess` اضافه کنید:

```apache
RewriteEngine On
RewriteRule ^$ /gilaclick-home/index.html [L]
```

فقط آدرس ریشه (`/`) به صفحه جدید می‌رود؛ بقیه مسیرها (فروشگاه، حساب کاربری، API و …) مثل قبل در اختیار وردپرس است.

**Nginx:**

```nginx
location = / { root /var/www/gilaclick-home; try_files /index.html =404; }
location ^~ /_astro/ { root /var/www/gilaclick-home; expires 1y; add_header Cache-Control "public, immutable"; }
```

### ۲. روی دامنه یا هاست دیگر
```bash
PUBLIC_STORE_API=https://gilaclick.ir/wp-json/wc/store/v1 npm run build
```
و دامنه جدید را در وردپرس مجاز کنید (مثلاً در `functions.php` قالب فرزند):

```php
add_filter( 'allowed_http_origins', function ( $origins ) {
    $origins[] = 'https://landing.example.com';
    return $origins;
} );
```

## نکات فنی

**حرکت و عملکرد**
- انیمیشن‌ها با CSS و فقط روی `transform`، `opacity` و `stroke-dashoffset` SVG؛ بدون کتابخانه انیمیشن و بدون ویدئو.
- انیمیشن‌های پیوسته در سکشن‌های خارج از دید متوقف می‌شوند (`IntersectionObserver`).
- ظاهر شدن با اسکرول برای هر المان فقط یک بار اجرا می‌شود؛ رسم تدریجی مدارها، نور بخش‌های تیره و پارالاکس ملایم با متغیر `--p` (پیشرفت اسکرول، حداکثر یک بار در هر فریم).
- در موبایل زمینه‌های مداری و پالس‌ها کاهش می‌یابند؛ `prefers-reduced-motion` همه حرکت‌ها را غیرفعال می‌کند.
- همه شنونده‌های اسکرول `passive` هستند و هیچ لایه تزئینی رویداد لمس یا کلیک را نمی‌گیرد.

**دسترس‌پذیری و سئو**
- یک `h1`، یک `h2` برای هر سکشن، `h3` برای کارت‌ها؛ لندمارک‌های استاندارد، لینک «پرش به محتوا».
- زیرمنوها با ماوس، لمس و صفحه‌کلید (Enter، Escape)؛ منوی موبایل با قفل فوکوس، Escape و غیرفعال کردن پس‌زمینه.
- متا تگ‌ها، Open Graph، داده ساختاریافته `Organization` و `WebSite` (با جستجوی سایت).
- نتیجه Lighthouse (موبایل و دسکتاپ): Accessibility ۱۰۰، Best Practices ۱۰۰، SEO ۱۰۰؛ Total Blocking Time صفر.

## مواردی که به تصمیم یا اطلاعات شما نیاز دارد

1. **اطلاعات تماس و شبکه‌های اجتماعی:** در سایت فعلی ایمیل، تلفن یا صفحه اجتماعی عمومی پیدا نشد و چیزی از خودمان نساختیم. کافی است در `src/config/site.ts` مقادیر `contact` و `social` را پر کنید تا در فوتر ظاهر شوند (آیکن تلگرام، اینستاگرام، واتساپ، آپارات، یوتیوب، X و گیت‌هاب آماده است).
2. **صفحات خدمات و تعرفه:** صفحه‌ای برای «تعرفه طراحی سایت»، «خدمات سئو» و «تعرفه پشتیبانی» در سایت وجود ندارد؛ این دکمه‌ها فعلاً به صفحه تماس می‌روند. بعد از ساخت صفحات، `links.services` را به‌روز کنید.
3. **دسته اقامتگاه‌ها:** دسته‌ای برای اقامتگاه وجود ندارد؛ کارت «اقامتگاه‌ها» فعلاً به جستجوی سایت برای «اقامتگاه» لینک شده (`links.guide.stays`).
4. **توضیح کوتاه محصولات:** «توضیح کوتاه» هر دو محصول در ووکامرس خالی است. با پر کردن آن، متن کارت‌ها مستقیماً از فروشگاه خوانده می‌شود.
5. **محصول شاخص:** با ستاره‌دار کردن یک محصول در ووکامرس، آن محصول در کارت بزرگ قرار می‌گیرد.
6. **لوگو:** نشانه SVG هماهنگ با هویت جدید طراحی شده (`src/components/brand/Logo.astro`). در صورت تمایل می‌توان لوگوی رسمی کتابخانه رسانه را جایگزین کرد.

**مشاهدات جانبی از سایت فعلی** (خارج از این مخزن):
- قیمت‌های صفحه اصلی فعلی (۸۹۰٬۰۰۰ و ۱٬۴۵۰٬۰۰۰ تومان) با قیمت‌های واقعی فروشگاه (۱٬۴۸۰٬۰۰۰ و ۱٬۹۴۰٬۰۰۰ تومان) یکسان نیست؛ صفحه جدید این مشکل را ندارد.
- در صفحه محصولات عبارت‌های «ارسال به سراسر ایران / ضمانت تعویض کالا» دیده می‌شود که برای محصول دانلودی مناسب نیست.
- عنوان سایت در وردپرس «معرفی گیلان» است و در عنوان همه صفحات دیده می‌شود.
